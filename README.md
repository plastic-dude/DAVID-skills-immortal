# DAVID.skills — Immortal Agent Skill Library

**Version 2.0 | 23,047 skills | 20 sources | Auto-loading**

## What This Is
A persistent, version-controlled skill library for AI agents. Every skill is a markdown instruction set that teaches an agent how to perform a specific task, think about a domain, or follow a protocol.

## Why It Exists
Pod restarts wipe local filesystems. GitHub doesn't. This repo is the immortal brain.
