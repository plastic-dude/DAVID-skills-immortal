## Usage

```bash
# Clone
git clone https://github.com/plastic-dude/DAVID-skills-immortal.git

# Extract skills
tar -xzf skills-archive.tar.gz
tar -xzf tree-of-knowledge.tar.gz

# Load into agent
cp -r skills/* /app/.agents/skills/
cp -r tree-of-knowledge/* /app/.agents/skills/
```
